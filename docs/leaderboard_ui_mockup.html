The phone can host the pitch

In solo play with no big screen, the mini pitch becomes the real one and this handset advances the physics. It holds a screen wake lock; if you background it the match pauses rather than dies, because the clock is match time.

A shout is never dropped

One in flight per dugout, one queued, and the queue is visible. Today's build silently discards shouts for ~13s of every 55s (main.js:393).

Only effective shouts score

+100 when a shout is followed by a goal within 45s, capped at 300 — instead of +50 for any shout, which pays you to spam the box.

The screen has its own room, and it can watch everyone else's. Centre court is one match at full size with both relays; the wall beneath it carries every other live room, so simultaneous play is visible rather than just claimed. Idle, it falls back to the leaderboard and the QR.

Whose game: the room's creator hosts it

Scan the QR on this screen and you're seated in its room, so your match opens on centre court. Start from your own phone and your phone hosts — you still appear on the wall, and the screen can pull you up.

Viewing costs one early return

game.js:400 runs ~1,300 lines of AI in a single update(). A viewer adds if (role==='viewer') return applyFrame(delta) and pauses physics — same sprites, same look, no AI. Wall tiles skip Phaser entirely: nine dots on a canvas.

Auto, until someone overrules it

The director promotes on drama — goal just scored, scores level, under 30 seconds left. Click a tile or press its number to pin, Esc to hand it back. A pin holds until the match ends, so nothing gets yanked away mid-shout.

Speed is locked in ranked

The 0.5–3x slider is hidden and the arena pushes speed: 1.0. It would otherwise distort "time to first goal" outright.

The host is trusted for physics only

It emits goal / kickoff / full_time with the match clock. The arena recomputes every point and never takes a submitted total.

Most tiles are solo runs

Against the house side there's no second dugout, so the red relay reads "no dugout here" rather than sitting empty. Press 2 to see it.

The chain takes 30–60 seconds and we're keeping it, so it has to be worth watching. Not a chat log — a signal moving down a wire, with the four players as parallel branches that resolve on their own clocks. That fan-out is real: captain.py:53 is a ParallelAgent.

Empty is an invitation

Before the first shout the panel reads "Nothing said yet. Shout, and watch it reach the pitch." — not a spinner and not a blank box.

Attributes land as they arrive

Each branch shows the deltas that player actually wrote. The squad starts reacting before the huddle finishes, so the pitch is never waiting on the slowest agent.

Where the 30–60s goes

Mostly the specialists being told to emit every attribute each call — 28 for the forward, ~44 for the keeper (forward.py:30). Emitting only what changed is the single biggest win and needs no change to the chain.

A dead branch still resolves

If a player agent times out its branch goes grey with "no answer". The huddle completes on three. Nothing hangs on the slowest link.

Two boards that never merge. The shipped red team is deliberately weak (README: 0W-1D-7L), so beating it and beating a person are not the same achievement.

Rating is stored, not ranked on

Elo needs repeat games to mean anything and most people here play once. It's computed and shown; wins then goal difference do the sorting. Flip it with one config change if the event runs long.

Email is never shown whole

Masked everywhere, stored as a salted hash for "best run per person", and purged after the event. The join screen says so plainly rather than burying it.

Abandoned matches score nothing

If the host drops for more than 30 seconds the match is marked abandoned and never reaches either board. The manager is told why, on the phone.
